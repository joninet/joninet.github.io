ActivaPro

Aplicación web para entrenadores deportivos

Estado: Completado
Fecha: 2023 - 2024
Equipo: Individual

Descripción del Proyecto

ActivaPro es una aplicación web completa diseñada para entrenadores personales y profesionales del fitness. Permite gestionar de manera eficiente a los clientes, crear rutinas de entrenamiento personalizadas, registrar el seguimiento del progreso y generar reportes detallados del desempeño.

La plataforma combina un backend robusto con Django REST Framework y una interfaz moderna desarrollada en React, proporcionando una experiencia de usuario fluida y receptiva en todos los dispositivos.

Desafíos y Soluciones

Desafío: Sincronización en tiempo real

Solución: Implementé WebSockets con Django Channels para sincronización en tiempo real entre entrenador y cliente, permitiendo actualizaciones instantáneas sin recargar la página.

Desafío: Exportación de reportes

Solución: Utilicé ReportLab y WeasyPrint para generar PDFs dinámicos con gráficos de manera asíncrona usando Celery, mejorando el rendimiento.

Desafío: Manejo de múltiples clientes

Solución: Implementé sistema de roles y permisos con Django Guardian, con caché en Redis para optimizar las consultas de acceso.
